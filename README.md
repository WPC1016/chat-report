# chat-report 聊天记录可视化报告

把已导出的聊天记录文件（微信 / QQ / Telegram 等）变成一份多页可视化报告：消息量、时间规律、高频词云、双方对比、那些「最」的瞬间。

**全程浏览器本地解析，数据不上传任何服务器。**

## 功能

- 支持格式：JSON / CSV / TXT / HTML，自动识别
- 总览：可解析消息数、聊天日、会话段、月度趋势、消息类型占比
- 双方对比：消息量/字数/表情包柱状图、回复速度、会话发起占比、明细表
- 时间规律：7×24 热力图、24 小时分布、星期分布
- 话题：整体词云 + 双方各自词云 + Top20 高频词（Intl.Segmenter 分词，无需后端）
- 那些「最」：消息最多的一天、最长消息、最晚消息、最快回复、最长会话、最长沉默、单日连发之王
- 一键导出 PDF（浏览器打印）

## 使用

```bash
npm install
npm run dev      # http://localhost:10600
```

导入你已导出的聊天记录文件即可。没有文件时可用「示例数据」体验。

### 数据来源建议

| 来源 | 方式 | 格式 |
|---|---|---|
| QQ | 消息管理器导出，或 QQChatExporter | JSON / TXT |
| 微信 | 手机多选合并转发另存，或 MemoTrace 等工具导出 | CSV / TXT |
| Telegram / Discord | 客户端自带导出 | JSON / HTML |
| 任意平台 | 复制粘贴成文本，每行 `[2024-01-01 10:00] 昵称: 内容` | TXT |

本工具只解析用户已导出的文件，不读取、不解密任何聊天软件本地数据库。

## 技术栈

Vue 3 + TypeScript + Vite + ECharts（含 wordcloud 插件）+ vue-router。纯前端 SPA，无后端、无数据库。

## 隐私

文件解析与全部统计均在你的浏览器内完成；数据仅存内存，刷新页面即清空。
